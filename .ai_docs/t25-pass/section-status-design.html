Какой статус действует для кода

Как с ответственными: действует ближайший статус выше.

  • Код с SpecTag проверяется по статусу, ближайшему выше правила, которое этот SpecTag называет.
  • Код без SpecTag не называет никакого правила. Поэтому раздел со своим статусом перечисляет пути к своему коду, и такой код проверяется по статусу раздела, в чьих путях он лежит. Код вне всех путей проверяется по статусу спецификации.
  • Раздел переводят в «одобрен» так же, как спецификацию: только когда у всего кода в его путях есть SpecTag.

Цена

  • У раздела станет два статуса. Один выводится из его правил: раздел одобрен, пока одобрены все правила в нём. Другой ставят ответственные раздела. Им нужны разные имена; выберем их вместе, если направление будет принято.
  • Инструменты SpecSheriff будут определять строгость отдельно для каждого раздела со своим статусом: чьи тесты запускать при push и где терпеть код без SpecTag.
  • Проект, где ни у одного раздела нет своего статуса, работает как сейчас.
