TRANSLATION: **Хук агента после правки.** После правки агента, сделанной инструментами редактирования файлов, или после команды оболочки, которую запускает агент, хук агента запускает инструменты SpecSheriff, если выполняется одно из следующего:

Если пользователь выбирает окно терминала, skill, когда окно закрывается, сообщает, чем настройки, которые печатает `sheriff settings`, отличаются от тех, что он показал раньше.

Обоснование: Эти настройки меняет только ответственный, через процедуру. Для `sheriff settings` в окне терминала нужен рабочий стол, который ответственный видит, а у ответственного, работающего удалённо, его нет, поэтому skill предлагает также чат.

Пример: Ответственный работает из браузера через Remote Control и просит агента выбрать расширение Views. `spec-settings` предлагает отдельное окно терминала или вопросы в чате, и ответственный выбирает чат. Skill запускает `sheriff settings extension views on`. Самая вероятная ошибка — открыть окно, не спрашивая, на рабочем столе, которого ответственный не видит.

- "the settings that only an owner of the specification changes": (а) настройки, которые вправе менять только ответственный; (б) настройки, которые фактически меняет только ответственный. Контекст за (а).
- "through a procedure": какая процедура, не названо; вероятно, та, что описана в узле о `sheriff settings`, на который стоит ссылка.
- "these settings": названы только в поле текста, не в обосновании; это настройки, которые меняет только ответственный за спецификацию.
- "asks the agent to choose the Views extension": (а) просит включить расширение Views для проекта; (б) просит агента самому сделать выбор. Контекст за (а).
- "`spec-settings` offers a separate terminal window or questions in the chat": по тексту узла окно предлагается только там, где skill может открыть его на рабочем столе машины с сессией; в примере не сказано, выполнено ли это условие, так что читатель может решить, что окно предлагается всегда.
