Строка называет того, кто одобряет или отзывает, только по этому адресу. Поэтому одобрение, которое агент делает от имени ответственного (§…), имеет ту же форму, что и собственное одобрение ответственного.
Строка без `withdrawn` — это одобрение. Одобрение формулировки узла действует, если последняя строка для sid узла и fingerprint этой формулировки — одобрение. Последняя строка — та, что стоит в файле последней.

Причина: Одобрение записывается отдельно от узла, чтобы никто не мог сделать узел одобренным, правя сам узел. В файл только дописывают строки, чтобы каждое одобрение оставалось в записи вместе с тем, кто его дал.
Пример: Правило R одобрили с формулировкой, у которой fingerprint F1, затем переформулировали и одобрили с fingerprint F2. Потом кто-то отозвал одобрение R, и в файл добавились отзыв для F1, а затем отзыв для F2. Одобрения формулировки R, которое действует, нет, поэтому R — черновик, а последнее одобрение R — строка, одобрившая F2. Вероятная ошибка — считать R одобренным, потому что в файле есть строка, одобряющая его текущую формулировку, хотя более поздняя строка отзывает это одобрение.
