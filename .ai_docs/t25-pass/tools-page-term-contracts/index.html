Узлы-термины вне раздела контрактов · Term nodes outside the contracts section

tools 7.1.3a (new) · new:tools-7-1-term-contracts · предложение от 2026-11-22 · ждёт вашего согласия
Обоснование
Раздел контрактов — единственная часть спецификации, которая хранится в specs/contracts/, поэтому папка файла узла-термина показывает, находится ли узел в этом разделе.
Reason
The contracts section is the only part of the specification kept in specs/contracts/, so the folder of a term node's file shows whether the node is in that section.

Новое, предложено рецензентом.

Формулировка по частям

Щелчок по части выделяет узлы, на которые она ссылается; щелчок по узлу внизу выделяет части, которые на него ссылаются.
