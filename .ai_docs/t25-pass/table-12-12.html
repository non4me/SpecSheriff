    RecordType

    A RecordType (§s-6eb92ddch7shuvu) is the format of data that a part of the system outputs and keeps in its store. It belongs to the API of that part of the system. Other parts of the system may use that data in whole or in part. In the specification, a part of the system is described by a top-level section of the base specification or by a domain. In the code, a part of the system is a module or a component. Data in one format has one RecordType. It is declared in the only section of the base specification that describes where data in that format first appears. The exception is a fragment of a format, such as an address. Fragments are declared in the contracts section (§s-z6tq6a3btnvvwx7), and any section may reuse them. RecordType names are unique across the specification, regardless of letter case.

    Two descriptions of one format drift apart over time. The parts of the system that read the data then cannot tell which description is valid. A format declared once, under one name, by whoever changes it, has nothing to drift from.

    RecordType

    RecordType (§s-6eb92ddch7shuvu) — это формат данных, которые часть системы выдаёт и хранит в своём хранилище. Он относится к API этой части системы. Другие части системы могут использовать эти данные целиком или частично. В спецификации часть системы описывает раздел верхнего уровня базовой спецификации или домен. В коде часть системы — это модуль или компонент. У данных одного формата один RecordType. Он объявляется в том единственном разделе базовой спецификации, который описывает, где данные этого формата появляются впервые. Исключение — фрагмент формата, например адрес. Фрагменты объявляются в контрактах (§s-z6tq6a3btnvvwx7), и их может переиспользовать любой раздел. Имена RecordType уникальны во всей спецификации без учёта регистра букв.

    Два описания одного формата со временем расходятся. Тогда части системы, которые читают эти данные, не могут понять, какое описание верно. Формату, объявленному один раз, под одним именем, тем, кто его меняет, расходиться не с чем.

    RecordType variants

    A RecordType variant declares the fields that a data record of a RecordType (§s-7vm323mhry2enx3) holds because of the values of some fields of that RecordType. The fields of the RecordType whose values decide this are the fields that select a RecordType variant. They are named by the RecordType itself or by a RecordType that it refines. Each combination of their values, one value for each field, has its own RecordType variant if the combination adds fields of its own, and only then. A RecordType variant is a RecordType that: - is declared where the RecordType that it is a variant of is declared: in the same section of the base specification or in the contracts section (§s-z6tq6a3btnvvwx7); - has a refines link (§s-sn6au3vcr9uy5pm) to that RecordType; - names the values it corresponds to, one value for each field that selects a RecordType variant. A data record holds the fields of its RecordType variant alongside the fields of its RecordType. The name of each field that a RecordType variant declares differs from the name of every field that its RecordType declares or takes through refines from another RecordType.

    Where the values of some fields decide which other fields a data record holds, a RecordType alone does not describe every field that the parts of the system that read its data records can expect. Its RecordType variants describe the rest. Since they are declared where the RecordType is declared, those parts of the system find the whole description of the data records where they look for the RecordType (§s-7vm323mhry2enx3).

    Варианты RecordType

    Вариант RecordType объявляет поля, которые запись данных RecordType (§s-7vm323mhry2enx3) содержит из-за значений некоторых полей этого RecordType. Эти поля — поля, которые выбирают вариант RecordType. Их называет сам RecordType или RecordType, который он уточняет. Каждое сочетание их значений, по одному значению каждого поля, имеет свой вариант RecordType, если это сочетание приносит собственные поля, и только тогда. Вариант RecordType — это RecordType, который: - объявлен там же, где RecordType, вариантом которого он является: в том же разделе базовой спецификации или в контрактах (§s-z6tq6a3btnvvwx7); - ссылается через связь refines (§s-sn6au3vcr9uy5pm) на этот RecordType; - называет значения, которым он соответствует, по одному значению каждого поля, которое выбирает вариант. Запись данных содержит поля своего варианта рядом с полями своего RecordType. Имя каждого поля, которое объявляет вариант RecordType, отличается от имени любого поля, которое его RecordType объявляет сам или берёт из RecordType, который он уточняет.

    Когда значения одних полей определяют, какие ещё поля содержит запись данных, сам RecordType описывает не все поля, которых могут ожидать части системы, читающие его записи данных. Остальное описывают его варианты RecordType. Поскольку варианты объявлены там же, где RecordType, эти части системы находят полное описание записей данных там, где ищут сам RecordType (§s-7vm323mhry2enx3).
