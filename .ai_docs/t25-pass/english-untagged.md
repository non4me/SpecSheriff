# "The list of code that carries no SpecTag", a new node of the appendix of the tools, agreed on 2026-11-22

## Title

The list of code that carries no SpecTag

## Text

`sheriff untagged` lists, by file and symbol, the system's code (§s-hheus6f395ynqvc) that carries no SpecTag (§s-8xw4mgvpexyvw5q). The check for code without a SpecTag names this command in its warning and in its refusal (§s-kkbqcb9xrpaepwn).

## Reason

The check for code without a SpecTag covers all such code in one warning, so that the warning does not bury the other findings (§s-kkbqcb9xrpaepwn). `sheriff untagged` lists that code symbol by symbol for whoever has to bind each symbol to the rules it implements.
