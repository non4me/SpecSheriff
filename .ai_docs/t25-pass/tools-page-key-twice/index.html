Обоснование
Парсер JSON оставляет одно из значений, записанных под ключом, и молча отбрасывает остальные, поэтому ключ, записанный больше одного раза, виден только в тексте файла.
Reason
A JSON parser keeps one of the values written under a key and silently drops the others, so only the file's text shows a key written more than once.

Как было; «twice» заменено на «more than once», как в согласованном узле о слиянии.

It refuses each of these files whose text is not valid JSON, naming the file and the line at which parsing failed.
