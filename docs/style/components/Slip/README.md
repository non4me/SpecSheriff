# Slip

A slip shows a rule as it is written, with the stamp that judges it on its lower edge.

- Use `ss-slip` on a block holding the rule's text in the typewriter face; mark its fault with `ss-mark` or `ss-ring`, and end the block with one `ss-stamp` naming the fault.
- The stamp overhangs the slip's lower edge by design; leave `space-6` below a slip for it.
- A slip quotes a rule; a rule's text in running prose is a quotation, not a slip.
