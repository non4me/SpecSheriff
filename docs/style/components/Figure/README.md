# Figure

A figure is a picture with its caption.

- Use `ss-figure` on a `figure` holding an `img` and a `figcaption`; the picture gets a `border-line` edge in `ink`, the caption the `caption` style in `ink-soft`.
- The pictures come from `docs/images/`: the PNG for a page, the SVG where it must scale. Every picture has its `alt` text.
