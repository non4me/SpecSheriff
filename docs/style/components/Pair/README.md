# Pair

A pair sets what went wrong beside what to write instead.

- Use `ss-pair` on a block of two children; give each a `ss-pair__label` ("A year later", and "Instead" with `ss-pair__label--instead`) and a paragraph.
- The halves stand side by side and stack on a narrow screen; the gap is `space-6`.
- The first half tells what happened, in the past; the second gives the rule as it should be written.
