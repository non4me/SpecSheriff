# The SpecSheriff mark

The mark is a sheriff's star drawn as one line, with an S inside it. The drawings here are the
owner's: `coin.svg`, the coin for full-size use; `icon.svg`, the star for icons up to 128 px, its line
heavier so that it holds at small sizes; `star.svg`, the star above that. `favicon-16.svg` and
`favicon-32.svg` are the browser's icons at 16 and 32 px, where the rings of the line drawing merge and
its S is lost: each is drawn on its own grid of pixels, the star filled, the S cut through it from the
upper right inner corner to the lower left one, the ends of the rays thickened; the owner chose them
from several such drawings. `exports/` holds everything made
from them — the coin in light and dark (the README shows the dark one on every ground), the star for a dark ground, the browser's
icons, the icons of an installed app and the repository's social preview — rendered by
`node _promo/brand/render.mjs`. An export is never edited: the drawing is changed and the script run again.
