# Frame

The frame is the double rule round a whole card, as a ledger page is ruled round its edge.

- Use `ss-frame` once, on the outermost block of a card or a poster; it draws `border-frame` double in `ink` with `space-8` inside.
- Inside it the card runs top to bottom: a `ss-kicker`, the title, the content, then the brand and a line of the reason at the foot.
- Never frame a block inside a frame, nor a ticket.
