# Prose

Prose is the body of an article or of any page of running text: the `text` face for reading, the `display` face for headings, the typewriter for code.

- Wrap the text in `ss-prose`: it keeps the column to `measure`, spaces paragraphs `space-4` apart and headings `space-7` above.
- Headings are `h2` to `h4`, in the `display` face; the page's `h1` stands above the prose.
- A code block is a `pre` on `ticket` with a `border-line` edge; it scrolls sideways rather than wrapping.
- A quotation is a `blockquote` in a dashed line, in `ink-soft`.
