# Figure

A figure is a picture with its caption.

- Use `ss-figure` on a `figure` holding an `img` and a `figcaption`; the picture gets a `border-line` edge in `ink`, the caption the `caption` style in `ink-soft`.
- The pictures come from `_promo/images/`: on a page, the picture's own page in `html/`, its text live and with no edge; the PNG for a post, the SVG where it must scale. Every picture shown as an image has its `alt` text.
