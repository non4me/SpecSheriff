# Ledger

A ledger is a table drawn as the ruled lines of an account book.

- Wrap a `table` in a `ss-ledger` block, which scrolls sideways on a narrow screen.
- Headings take the `kicker` style over a `border-line` rule in `ink`; rows are parted by `border-hair` lines in `rule`; figures line up (tabular numbers).
- No zebra stripes and no boxes round cells.
